1. 이 도구는 무엇인가요

Kay Archive Uploader(이하 "도구")는 유튜브 채널 '케이의 기록실'(@kay.rewind) 운영자가 자기 채널을 관리하려고 만든 내부 도구입니다. 일반 사용자에게 제공하지 않으며, 운영자 본인 계정으로만 로그인해 사용합니다.

2. 접근하는 정보

도구는 Google OAuth로 운영자가 허용한 범위에서 다음 YouTube 정보에 접근합니다.

  • 운영자 채널의 영상 업로드, 제목·설명·태그·썸네일 수정, 댓글 작성 (YouTube Data API)
  • 운영자 채널의 영상 목록과 공개 통계 읽기 (YouTube Data API)
  • 운영자 채널의 분석 데이터 읽기 (YouTube Analytics API)
  • 도구가 직접 올린 Google Drive 파일만 다루기(drive.file 범위 — 공유 링크를 만든 뒤 삭제)

3. 정보의 사용과 보관

  • 위 정보는 운영자 채널 관리와 성과 분석에만 씁니다.
  • 인증 토큰은 운영자 컴퓨터에만 저장하며 외부 서버로 보내지 않습니다.
  • 정보를 판매하거나 제3자에게 제공하지 않으며, 광고에 쓰지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

도구가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. 도구는 YouTube 서비스 약관과 Google 개인정보처리방침을 따르는 YouTube API 서비스를 사용합니다.

5. 권한 철회

운영자는 언제든 Google 계정 보안 설정에서 도구의 접근 권한을 철회할 수 있습니다.
